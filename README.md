# Buddy Skills

The agent skills packaged with [Buddy](https://github.com/buddy-hq/buddy), available as
ordinary skill directories for independent installation.

Each directory under [`skills/`](skills/) contains the exact runtime files from Buddy's last
deliberate skill or application release. Work in progress on Buddy's `main` branch is not published
here. Some skills use Buddy-specific tools and work best inside Buddy.

This is a generated mirror. Make skill changes in the Buddy repository; its existing skill
publisher updates this repository from the same validated system pack delivered to Buddy apps.

The initial contents were backfilled from Buddy `v0.0.63`.
The skills packaged with Buddy, published for independent installation.
